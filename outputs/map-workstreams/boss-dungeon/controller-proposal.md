# boss-dungeon 总控集成提案

## 当前请求

无共享变更请求。本候选可作为隔离体验由总控审阅，但不应直接连接正式 Person、Capability、Evidence、Progress、Identity 或发布路径。

## 未来可能需要的总控能力

若真人门槛通过并准备集成，建议总控评估一个只读的“前四图证据快照”输入和一个经授权、可审计的“综合项目练习证据”提交接口。地图不定义或实现该共享接口。

## 兼容性

- 输入必须引用共享 Evidence Ledger 的稳定标识，不复制人员或能力事实。
- 界面必须持续区分事实、人工判断、模型建议和系统状态。
- 合成演练与真实项目数据必须有不可混淆的来源和用途标记。

## 迁移

当前原型不需要迁移。未来接入时应由总控将 `sessionStorage` 合成状态视为不可导入数据，禁止把原型回执批量迁入正式证据账本。

## 所需证据

- 本候选在 390、768、1280 CSS 像素下的机器通过证据。
- 目标学习者对安全边界、角色、约束和证据追溯的真人通过证据。
- 总控对身份、权限、隐私、审计、数据保留和跨地图术语连续性的集成回归。
