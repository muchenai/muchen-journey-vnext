# 新手村第一条黄金路径

状态：`ISOLATED_DRAFT_BUILD`  
契约：`outputs/map-workstreams/newcomer-village/contract.json`  
可运行入口：`prototypes/newcomer-village/index.html`

## 人的结果

新人先读取探索营成长基线与岗位/组织上下文的来源、状态和事实边界，再选择并完成一项真实的小型融入行动，最后留下可供人工复核的角色准备度或协作习惯证据草稿。

“真实行动”发生在工作场景中，不发生在页面点击里。原型要求学员明确选择协作动作与发生时间，完成后只记录协作角色、观察到的期待或约定、下一次可重复行为，并确认不含真人姓名、客户信息或机密细节。

## 隔离边界

- 探索营仍为 `READY_FOR_HUMAN`；本路径不假设其真人已经通过。
- 原型中的成长基线、组织单元与岗位字段均为显式合成 fixture，不代表任何真人或公司事实。
- Person、Capability、Evidence、Progress、Identity 与岗位/组织上下文均保持只读。
- 未完成草稿只保存在当前浏览器 tab 的 `sessionStorage`；它是可丢弃草稿，不是第二事实源。
- 页面不创建邀请、不调用业务 API、不写共享 Evidence Ledger、不执行生产或发布动作。
- 机器通过最多使候选进入 `READY_FOR_HUMAN`；真人门槛与总控集成仍独立。

## 路径

1. 抵达新手村并看见探索营真人门槛。
2. 读取合成成长基线和岗位/组织字段结构。
3. 从三项有边界的协作动作中选择一项并确定时间。
4. 在真实工作场景完成行动。
5. 记录最小、非敏感的观察与可重复行为。
6. 核对明确标记“本地临时草稿 · 未提交”的证据回执。

## 真人门槛

真人验收必须使用目标新人、未提示协议与真实工作协作机会。至少验证：输入来源辨识、3 分钟内独立形成行动卡、一个工作日内真实完成互动、证据草稿经人工复核、进度清晰度与继续意愿。详细阈值以地图契约为准，机器截图或自动化结果不能代替这些证据。
