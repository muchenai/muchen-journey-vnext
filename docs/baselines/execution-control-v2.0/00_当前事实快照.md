## 事实解释

- `G1=PASS` 只证明内容和 Owner 决定已绑定；不证明生成后的 JSON 已与 Runtime 兼容。
- 正式内容包 hash 修复只可改变 hash 计算和由此派生的索引/引用。如果任何业务字段、任务语义、Rubric、Reviewer、SLA、数据策略或来源字段发生变化，必须停止并重新走 Owner 批准。
- 运维插件失败是工具合同版本漂移，不是产品合同应降级的证据。它阻塞 G4/发布解释工具，不应诱导 Mini 修改产品事实。
- 现有大量旧镜像和证据是历史机器结果；没有绑定最终 commit SHA 的结果不得计入新候选 Gate。
