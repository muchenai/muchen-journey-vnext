# 模块分册 04｜交付线公会

> 公会 Owner：段超群  
> 首发定位：交付线通用能力的短周期实践空间；不是聊天群、内容目录、生产项目系统或自动人才分流器。  
> 内容状态：`MODULE_APPROVED / FIRST_PLUGIN_CONTENT_BINDING_REQUIRED`

## 1. 使用者结果

成员围绕一项明确的交付通用能力，在短周期内完成模拟或受控真实任务，提交可复核产物，经导师返工/通过后形成公会实践证据和下一次练习建议。

## 2. 共享平台与公会插件

共享平台提供：身份、权限、任务、提交、审核、证据、积分、通知、申诉、审计、发布。

交付线公会插件只定义：

- 公会名称、使命、Owner、目标能力；
- 适用人群、加入/暂停/退出条件；
- 能力等级说明和行为锚点；
- 首批任务包、Rubric、导师池；
- 周期/赛季节奏、证据有效期；
- 受控真实任务边界；
- 下一任务/继续练习/转向/暂缓建议。

禁止复制账户、任务状态、积分、证据、通知、申诉和审计系统。

## 3. 首发范围

9/1只交付一个“交付线公会”插件和一条完整实践路径；不要求一次建立七个交付线分会。段超群在内容包中确定首个能力主题。推荐选择能用公开/合成/脱敏材料评审的通用能力，例如：规则拆解、质量判断、问题提报、交接或复盘；推荐不等于批准。

首发不包含正式认证；页面不得把公会通过写成项目准入或岗位等级。

## 4. 黄金路径

1. 成员看见公会使命、目标能力、导师和边界；
2. 真人确认加入/试练资格，或按公开低影响条件加入；
3. 成员领取一项短周期任务；
4. 真实任务时继承新手村受控任务授权；
5. 成员提交产物，AI可自查；
6. 导师按Rubric返工/通过并写理由；
7. 通过后形成公会实践证据，积分另账；
8. 真人给出下一任务、继续练习、转向或暂缓建议；
9. 成员可查看依据并申诉高影响判断。

## 5. 成员与任务状态分离

成员状态：`APPLIED / ACTIVE / PAUSED / EXITED`。任务仍使用共享正式状态机。成员活跃、任务通过和正式认证是三种不同事实。

系统不得按积分、活跃度或AI推荐自动加入、退出、转会、认证或产生岗位适配结论。

## 6. 导师池与运营

导师记录专业范围、可签署Evidence范围、容量、开放时段、SLA、回避关系和替补。公会Owner维护标准和任务，不得在无审查时自行更改高影响Rubric。

首发看板：活跃成员、待审、超时、返工、通过、导师容量、任务版本、证据有效期和安全例外。

## 8. 验收

- 3/3成员能说明公会目标、任务边界、导师和下一行动；
- 一条任务经历返工和通过；
- 导师在SLA内处理并留下可执行反馈；
- 技术证明公会没有复制共享核心；
- 真实任务通过授权和生产隔离负向测试；
- 积分/AI/活跃度无法产生加入、退出、认证或岗位结论。
